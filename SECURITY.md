# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in .folder, **please do not open a public issue.** Instead, report it privately so we can address it before it's disclosed.

📧 **Email:** [security@modpotato.dev](mailto:security@modpotato.dev)

Include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The version or commit where you observed the issue
- Any suggested fix, if you have one

## What to Expect

- **Acknowledgment** within 48 hours of your report.
- We'll work with you to understand and validate the issue.
- A fix will be prioritized based on severity.
- You'll be credited in the fix (unless you prefer to stay anonymous).

## Scope

The following are in scope:

- The .folder web application at [dotfolder.xyz](https://dotfolder.xyz)
- Authentication and session handling
- Namespace registration and API endpoints
- Data exposure or access control issues

The following are **out of scope**:

- Denial-of-service attacks
- Social engineering
- Issues in third-party dependencies (report those upstream)
- Self-XSS or issues requiring unlikely user interaction

## Bug Bounty

We don't currently offer a paid bug bounty program, but we genuinely appreciate responsible disclosure. All confirmed reporters will be credited in the project unless they opt out.

Thank you for helping keep .folder safe. 🙏
